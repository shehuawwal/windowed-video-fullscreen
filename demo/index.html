Windowed Video Fullscreen — test page

Serve this folder (python3 -m http.server in the repo root, then open http://localhost:8000/demo/) with the extension loaded. Default shortcut: Ctrl + Shift + F to toggle, Esc to exit.

1. Built-in video controls

Use the video's own fullscreen button or double-click it (Firefox). It should fill the tab, not the screen.

2. Custom player that exits on click (badly behaved site)

Click the video: this player calls exitFullscreen() on every click. With "Clicking the video never exits" on, it stays windowed. The ✕ button still exits.

3. Player inside a transformed, clipped container (social-feed style)

Transforms on a parent usually break "fixed" positioning. The player should still cover the whole tab.

4. Player wrapped in a link

While windowed, clicking the video must not follow the link (the URL should not change to #you-left).

5. Embedded player (iframe)

The iframe should grow to fill the tab, and its video to fill the iframe.
